# Dots & Boxes — legal pages

Public privacy policy and account deletion pages for the Dots & Boxes app,
served with GitHub Pages:

- https://sujan227.github.io/dots-and-boxes-legal/privacy-policy.html
- https://sujan227.github.io/dots-and-boxes-legal/delete-account.html

These files are generated. Edit the Markdown in the app repository
(`docs/legal/*.md`), run `dart run tool/build_legal_pages.dart` there, and
copy the resulting `*.html` files here.
